# Netcatty Mobile PRD(产品需求文档)

> 范围:**仅移动端**(iOS / Android)。桌面版能力仅作为参照,不在此文档范围内。
> 版本:v0.1(草案)· 分支:mobile · 日期:2026-08
> 前置文档:技术可行性方案见 `README.md`(同目录);本文档只描述**产品需求**,不涉及技术实现。

## 1. 产品概述

### 1.1 定位

Netcatty 移动版是桌面 SSH 管理器的**移动端配套客户端**:用户离开桌面后,用手机随时连接自己管理的服务器,完成应急排障、日志查看、轻量运维等操作。

- 一句话定位:**随时随地,连上你的服务器。**
- 与桌面版的关系:同一品牌、同一 vault 数据心智;移动版是补充,不是替代。

### 1.2 目标用户

| 画像 | 特征 | 核心诉求 |
|---|---|---|
| 桌面版现有用户(运维/开发) | 已在桌面版维护主机、密钥 | 数据无缝带到手机;移动场景可用 |
| 无桌面版背景的轻量用户 | 有少量服务器,偶尔手机应急 | 快速配置、连接、看日志 |

### 1.3 产品目标

1. 首版交付**最小核心闭环**:配置 → 连接 → 操作(终端/SFTP/转发)全程流畅。
2. **体验优先**:终端交互、键盘、性能达到"可日常使用"水准(原生终端,拒绝 WebView 兜底)。
3. 安全底线:密钥、host key、凭据全部落系统安全存储,host key 强校验。

### 1.4 非目标(首版明确不做)

- 云同步、AI 助手、系统管理器、插件系统、脚本自动化、MCP、telnet/serial/mosh/et、x11 转发。
- 桌面版专属能力(多窗口、托盘、全局快捷键)。
- 移动端不做「远程网关中转」模式(保持本地直连)。

## 2. 目标用户与使用场景

> ⚠️ 以下场景为初稿,需产品确认/补充。

| # | 场景 | 用户动作 | 期望 |
|---|---|---|---|
| S1 | 应急排障(在家/路上) | 收到告警 → 打开 App → 连上生产机 → 看日志/进程 | 30 秒内完成连接;终端可读 |
| S2 | 路上查日志 | 连服务器 `tail -f` | 滚动流畅,可搜索 |
| S3 | 快速改配置 | 编辑配置文件(vi/nano) | 虚拟键盘可用,方向键/ESC 可达 |
| S4 | 传文件 | 从手机上传/下载小文件(日志、配置、包) | SFTP 列表浏览、传输进度可见、可取消 |
| S5 | 临时端口转发 | 转发本地端口访问内网服务 | 转发状态可见、可停 |
| S6 | 新设备配置 | 首次使用,导入/新建主机与密钥 | 引导清晰,密钥生成/导入顺畅 |

## 3. 功能需求

首版范围 = 最小核心。优先级:P0(首版必达)/ P1(首版应达,可后置到首个补丁)/ P2(首版不达,列入后续)。

### 3.1 vault:主机与分组(P0)

| 需求 | 优先级 | 验收标准 |
|---|---|---|
| 主机 CRUD:新建/编辑/删除 SSH 主机 | P0 | 支持 host、port、用户名、认证方式(密码/密钥)配置;删除有二次确认 |
| 主机分组:创建/重命名/删除/归类 | P0 | 分组树可折叠;主机可归属多级分组 |
| 主机搜索 | P0 | 按主机名/IP 过滤,列表即时刷新 |
| 最近连接 | P0 | 记录最近 N 条连接,一键重连 |
| 主机健康状态 | P2 | 可显示在线/离线(依赖网络探测,见非功能) |

### 3.2 认证与连接(P0)

| 需求 | 优先级 | 验收标准 |
|---|---|---|
| 密码认证 | P0 | 密码可临时输入或存 vault(落系统安全存储);错误提示明确 |
| 密钥认证 | P0 | 支持 ed25519/rsa 密钥;私钥落系统安全存储;支持 passphrase |
| **host key 验证** | P0 | 首次连接展示指纹并要求确认(TOFU);指纹变更时**阻断连接并告警**(防 MITM);支持 known_hosts 管理 |
| keyboard-interactive 认证 | P0 | 支持(桌面版已有同类流程) |
| 连接失败反馈 | P0 | 区分:网络不可达 / 认证失败 / host key 不匹配,给出可操作提示 |
| 连接超时 | P0 | 默认 10s 可配置;超时提示 |

### 3.3 SSH 终端(P0,核心体验)

| 需求 | 优先级 | 验收标准 |
|---|---|---|
| 交互终端 | P0 | 原生渲染;VT100/xterm 兼容;彩色/UTF-8 正常 |
| 滚动性能 | P0 | 大输出刷屏不卡顿(≥30fps 感知流畅);回滚查看历史输出 |
| 虚拟键盘布局 | P0 | 提供 Esc/Ctrl/Alt/Tab/方向键/常用符号行;可自定义 |
| 会话管理 | P0 | 多标签/多会话切换;会话断开可重连;App 杀进程后按策略恢复(见非功能) |
| 终端设置 | P1 | 字号、主题(明/暗/跟随系统)、字体 |
| 搜索回滚缓冲 | P1 | 在输出历史中搜索 |
| 复制/粘贴 | P0 | 长按选择复制;支持粘贴(受系统剪贴板权限约束) |
| 中断/信号 | P0 | Ctrl+C 等常用信号可达;悬挂时可发送中断 |

### 3.4 SFTP 浏览与传输(P1)

| 需求 | 优先级 | 验收标准 |
|---|---|---|
| 目录浏览 | P0 | 列表/网格;文件类型图标;排序;刷新 |
| 上传/下载 | P1 | 单选/多选;显示进度、速度、剩余时间;**可暂停/恢复/取消** |
| 断点续传 | P1 | 中断后重新传输可续传(至少同会话内) |
| 文件操作 | P1 | 新建目录、重命名、删除(二次确认)、修改权限(chmod) |
| 传输队列 | P1 | 并发传输数上限(默认 3,可配);队列顺序管理 |
| 大文件限制 | P1 | 单文件 ≥4GB 时给出明确提示(依赖底层能力,见验收风险) |

### 3.5 端口转发(P1)

| 需求 | 优先级 | 验收标准 |
|---|---|---|
| 本地→远程转发 | P1 | 配置本地端口/远端目标;转发状态实时显示 |
| 转发管理 | P1 | 列表展示、停止、删除;会话断开时自动清理 |
| 多规则 | P1 | 同会话最多 8 条转发规则 |

### 3.6 密钥管理(P0 基础 / P1 完整)

| 需求 | 优先级 | 验收标准 |
|---|---|---|
| 密钥导入 | P0 | 从文件导入 PEM/OpenSSH 格式;私钥落系统安全存储 |
| 密钥生成 | P1 | 生成 ed25519/rsa 密钥对;可复制公钥 |
| 密钥删除 | P0 | 删除有二次确认;删除后关联主机不可用需提示 |

### 3.7 snippets(P2)

| 需求 | 优先级 | 验收标准 |
|---|---|---|
| 命令片段库 | P2 | 常用命令分类保存;终端内一键插入 |
| 变量替换 | P2 | 片段支持占位符,插入时提示输入 |

### 3.8 设置(P0 基础)

| 需求 | 优先级 | 验收标准 |
|---|---|---|
| 主题/语言 | P0 | 明/暗/跟随系统;语言跟随系统或手动选择 |
| 安全设置 | P1 | 是否启用 App 锁(生物识别/PIN);锁定时断开活动会话(可配) |
| 关于/版本 | P0 | 版本号、开源声明、隐私政策入口 |

## 4. 非功能需求

### 4.1 安全(最高优先级)

| 需求 | 验收标准 |
|---|---|
| 凭据存储 | 密码/私钥/passphrase **只落**系统安全存储(Android Keystore 加密 / iOS Keychain),不落明文文件 |
| host key 校验 | 强制 TOFU;指纹变更默认阻断,用户显式确认才继续 |
| 屏幕锁定 | 开启 App 锁后,锁定时会话不可见、可配置自动断开 |
| 日志脱敏 | 错误日志不记录密码、私钥内容 |
| 私钥导出 | 导出前需用户确认并提示风险 |

### 4.2 性能

| 需求 | 验收标准 |
|---|---|
| 终端渲染 | 大输出(10MB+ 日志)滚动不卡顿;启动到首屏 < 2s(冷启动) |
| 传输 | 传输不阻塞终端交互;内存占用受控(流式读写,不整文件载入) |
| 包体 | Android APK ≤ 60MB(含原生库) |

### 4.3 网络

| 需求 | 验收标准 |
|---|---|
| 弱网 | 弱网下终端输入有本地回显策略与超时提示,不假死 |
| 网络切换 | WiFi↔蜂窝切换时给出提示,会话按策略重连或保持 |
| 后台 | 锁屏/切后台:默认保活 N 分钟(可配);前台恢复时快速重连 |

### 4.4 平台合规

| 需求 | 验收标准 |
|---|---|
| 商店政策 | 通过 Google Play / App Store 审核(隐私政策、权限最小化) |
| 权限 | 仅申请必需权限(网络、存储按需);拒绝权限时功能降级可用 |
| 深链 | 支持 `ssh://` 链接唤起(Android URL scheme / iOS Universal Link 评估) |

## 5. 版本规划

| 版本 | 范围 | 对应 Phase |
|---|---|---|
| **MVP(v1.0)** | vault(主机/分组)+ 认证(密码/密钥/host key)+ SSH 终端 + 密钥导入/删除 + 设置基础 | Phase 1 |
| **v1.1** | SFTP 浏览 + 传输(断点续传/暂停恢复)+ 端口转发 + 密钥生成 | Phase 2-3 |
| **v1.2** | 终端增强(搜索/主题定制)+ snippets + App 锁 | Phase 3 收尾 |
| **v2.0** | 云同步 + AI(API 直连)+ 系统管理器 + iOS 完整适配 | Phase 4-5 |

> 平台节奏:Android 先行(首端);iOS 以 IPA 打包验证为主,完整商店发布后置。

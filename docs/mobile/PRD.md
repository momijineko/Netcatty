# Netcatty Mobile PRD(产品需求文档)

> 范围:**仅移动端**(iOS / Android)。桌面版能力仅作为参照,不在此文档范围内。
> 版本:v0.1(草案)· 分支:mobile · 日期:2026-08
> 前置文档:技术可行性方案见 `README.md`(同目录);本文档只描述**产品需求**,不涉及技术实现。

---

## 1. 产品概述

### 1.1 定位

Netcatty 移动版是桌面 SSH 管理器的**移动端配套客户端**:用户离开桌面后,用手机随时连接自己管理的服务器,完成应急排障、日志查看、轻量运维等操作。

- 一句话定位:**随时随地,连上你的服务器。**
- 与桌面版的关系:同一品牌、同一 vault 数据心智;移动版是补充,不是替代。

### 1.2 目标用户

| 画像 | 特征 | 核心诉求 |
|---|---|---|
| 桌面版现有用户(运维/开发) | 已在桌面版维护主机、密钥 | 数据无缝带到手机;移动场景可用 |
| 无桌面版背景的轻量用户 | 有少量服务器,偶尔手机应急 | 快速配置、连接、看日志 |

### 1.3 产品目标

1. 首版交付**最小核心闭环**:配置 → 连接 → 操作(终端/SFTP/转发)全程流畅。
2. **体验优先**:终端交互、键盘、性能达到"可日常使用"水准(原生终端,拒绝 WebView 兜底)。
3. 安全底线:密钥、host key、凭据全部落系统安全存储,host key 强校验。

### 1.4 非目标(首版明确不做)

- 云同步、AI 助手、系统管理器、插件系统、脚本自动化、MCP、telnet/serial/mosh/et、x11 转发。
- 多窗口、全局快捷键:移动端无对应系统机制,以多会话标签页(3.3)、App Shortcuts、`ssh://` 深链替代;托盘本体不移植,其保活价值由后台保活(4.3)承担。
- 桌面 UI 定制(自定义 CSS、应用图标变体、全局键位方案):移动端不做。
- SFTP 双窗格(桌面分屏对比):移动端不做,以单窗格 + 书签替代。
- 本地终端(连接本机 shell):移动端无意义,不做。
- 资源管理器右键菜单集成(Windows 专属):移动端无对应机制。
- App 级网络代理设置(服务于云同步/AI):随云同步后置;移动端系统级代理自动生效。
- 不做**自建网关**中转模式(Guacamole 类,需自架服务器);支持**跳板机(ProxyJump)**模式(见 3.2.1),保持本地直连语义。

## 2. 目标用户与使用场景

> ⚠️ 以下场景为初稿,需产品确认/补充。

| # | 场景 | 用户动作 | 期望 |
|---|---|---|---|
| S1 | 应急排障(在家/路上) | 收到告警 → 打开 App → 连上生产机 → 看日志/进程 | 30 秒内完成连接;终端可读 |
| S2 | 路上查日志 | 连服务器 `tail -f` | 滚动流畅,可搜索 |
| S3 | 快速改配置 | 编辑配置文件(vi/nano) | 虚拟键盘可用,方向键/ESC 可达 |
| S4 | 传文件 | 从手机上传/下载小文件(日志、配置、包) | SFTP 列表浏览、传输进度可见、可取消 |
| S5 | 临时端口转发 | 转发本地端口访问内网服务 | 转发状态可见、可停 |
| S6 | 新设备配置 | 首次使用,导入/新建主机与密钥 | 引导清晰,密钥生成/导入顺畅 |

## 3. 功能需求

首版范围 = 最小核心。优先级:P0(首版必达)/ P1(首版应达,可后置到首个补丁)/ P2(首版不达,列入后续)。

### 3.1 vault:主机与分组(P0)

| 需求 | 优先级 | 验收标准 |
|---|---|---|
| 主机 CRUD:新建/编辑/删除 SSH 主机 | P0 | 支持 host、port、用户名、认证方式(密码/密钥)配置;删除有二次确认;**支持复制主机**(快速克隆配置,对齐桌面 duplicate) |
| 主机分组:创建/重命名/删除/归类 | P0 | 分组树可折叠;主机可归属多级分组 |
| 主机搜索 | P0 | 按主机名/IP 过滤,列表即时刷新 |
| 最近连接 | P0 | 记录最近 N 条连接,一键重连 |
| 主机健康状态 | P2 | 可显示在线/离线(依赖网络探测,见非功能) |
| 主机备注/标签 | P2 | 支持 tags/notes 字段(对齐桌面 Host 模型) |
| 启动命令 | P2 | 连接后自动执行命令(对齐桌面 startupCommand,如自动跳目录/启动 tmux) |
| 主机置顶 | P2 | pinned 置顶排序(对齐桌面) |
| 分组级连接设置 | P1 | 分组可配置默认 端口/用户名/密钥/证书/环境变量等(对齐 GroupSshSettings,主机可覆盖) |
| **主机/分组导入** | P1 | 导入主机与分组(CSV/常见格式),可选目标分组,提供模板(对齐 ImportVaultDialog;支撑与桌面版互通) |
| **vault 备份** | P2 | 本地备份:自动/手动创建、列表、恢复、保留策略(对齐 vaultBackups bridge;防数据丢失) |
| 主机笔记(Markdown) | P2 | 主机关联笔记,支持 Markdown 与图片(对齐 NotesManager) |
| 主机点击行为 | P2 | 点按连接/长按更多操作(对齐 hostClickBehavior) |
| 扫码配置/连接 | P2 | 扫描二维码导入主机配置/发起连接(移动端特有) |

### 3.2 认证与连接(P0)

| 需求 | 优先级 | 验收标准 |
|---|---|---|
| 密码认证 | P0 | 密码可临时输入或存 vault(落系统安全存储);错误提示明确 |
| 密钥认证 | P0 | 支持 ed25519/rsa 密钥;私钥落系统安全存储;支持 passphrase |
| **host key 验证** | P0 | 首次连接展示指纹并要求确认(TOFU);指纹变更时**阻断连接并告警**(防 MITM);支持 known_hosts 管理 |
| keyboard-interactive 认证 | P0 | 支持(桌面版已有同类流程) |
| 连接失败反馈 | P0 | 区分:网络不可达 / 认证失败 / host key 不匹配,给出可操作提示 |
| 连接超时 | P0 | 默认 10s 可配置;超时提示 |
| known_hosts 管理 | P2 | 独立界面:查看已信任主机指纹、**删除**(删除后下次连接重新验证)、批量导入 |
| 算法兼容模式 | P2 | 连老设备(ssh-rsa/SHA-1)失败的兼容开关(对齐 legacyAlgorithms/skipEcdsaHostKey) |
| 保活设置 | P2 | keepalive 间隔/超时可配(主机级) |
| SSH agent / agent forwarding | P2 | 记录:移动端无系统 agent,跳板链 agent 转发需内置 agent,复杂度高,后置 |
| 环境变量 | P2 | 连接时注入环境变量(envVars) |
| **证书认证** | P1 | 支持 SSH 证书认证(CA 签名,HostAuthMethod=certificate,桌面完整支持);**风险:移动端 JSch/libssh2 证书支持需 PoC 验证** |

### 3.2.1 跳板机与代理(P1)

> 内网穿透刚需:目标机在内网、手机在外网时,经跳板机连接。桌面版已完整实现(机制 = SSH direct-tcpip 通道链,与移动端 JSch/libssh2 等价),domain 逻辑可直接参考。

| 需求 | 优先级 | 验收标准 |
|---|---|---|
| 跳板机连接 | P1 | 主机配置支持「通过跳板机连接」,可配置**多级跳板链**;连接时逐跳建立再转发目标 |
| 每跳独立认证 | P1 | 每级跳板独立配置 密码/密钥/passphrase,与目标认证互不影响 |
| 每跳 host key 验证 | P1 | 每级跳板与目标均执行 TOFU 验证(对齐桌面行为) |
| HTTP/SOCKS 代理 | P1 | 支持 HTTP/SOCKS 代理(会话级与跳板级);移动端不做 ProxyCommand(依赖本地命令) |
| 错误定位 | P1 | 跳板连接失败时明确指出失败在哪一跳(哪台主机、认证失败还是网络不可达) |

> 桌面实现参考:`sftpBridge/openConnection.cjs` `connectThroughChainForSftp`(逐跳 `forwardOut` 链式连接)、`sshBridge.cjs` `createProxySocket`(HTTP/SOCKS)。

## 4. 非功能需求

### 4.1 安全(最高优先级)

| 需求 | 验收标准 |
|---|---|
| 凭据存储 | 密码/私钥/passphrase **只落**系统安全存储(Android Keystore 加密 / iOS Keychain),不落明文文件 |
| host key 校验 | 强制 TOFU;指纹变更默认阻断,用户显式确认才继续 |
| 屏幕锁定 | 开启 App 锁后,锁定时会话不可见、可配置自动断开 |
| 日志脱敏 | 错误日志不记录密码、私钥内容 |
| 私钥导出 | 导出前需用户确认并提示风险 |
| 剪贴板敏感提示 | 复制密码/私钥内容时提示系统剪贴板泄露风险(移动端特有) |

### 4.2 性能

| 需求 | 验收标准 |
|---|---|
| 终端渲染 | 大输出(10MB+ 日志)滚动不卡顿;启动到首屏 < 2s(冷启动) |
| 传输 | 传输不阻塞终端交互;内存占用受控(流式读写,不整文件载入) |
| 包体 | Android APK ≤ 60MB(含原生库) |

### 4.3 网络

| 需求 | 验收标准 |
|---|---|
| 弱网 | 弱网下终端输入有本地回显策略与超时提示,不假死 |
| 网络切换 | WiFi↔蜂窝切换时给出提示,会话按策略重连或保持 |
| 后台保活 | **Android:前台服务 + 常驻通知**(等价桌面托盘,通知带会话操作按钮:跳转/关闭/重连;保活时长可配);**iOS 后台受限**,无对应机制,前台恢复时快速重连 |
| 自动重连 | 会话断开按策略自动重连(指数退避,可配;对齐桌面 retry 逻辑) |

### 4.4 平台合规

| 需求 | 验收标准 |
|---|---|
| 商店政策 | 通过 Google Play / App Store 审核(隐私政策、权限最小化) |
| 应用内更新 | 检查/下载/安装更新(Android:Expo Updates OTA 或商店;iOS:商店审核通道;对齐桌面 autoUpdate) |
| 权限 | 仅申请必需权限(网络、存储按需);拒绝权限时功能降级可用 |
| 深链 | 支持 `ssh://user@host:port` 唤起,**唤起后确认可直连**(而非仅打开 App) |
| Widget | 桌面小组件快速连接(托盘替代品,P2 记录) |
| 深链(jms://) | jms:// 为桌面特有协议(配合 jms 工具),移动端后置(记录) |

## 5. 版本规划

| 版本 | 范围 | 对应 Phase |
